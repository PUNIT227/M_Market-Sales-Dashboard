# M_Market-Sales-Dashboard
Power BI
## Overview

This project presents an interactive Power BI dashboard for Maven Market, designed to analyze sales performance, customer behavior, product trends, and business profitability. The dashboard enables stakeholders to monitor key business metrics and make data-driven decisions.

## Objectives

* Analyze sales performance across products, regions, and time.
* Track revenue, profit, orders, and customer growth.
* Identify top-performing products and underperforming categories.
* Build an interactive dashboard for business reporting.

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Modeling

## Dashboard Features

* Executive KPI Dashboard
* Revenue and Profit Analysis
* Product Performance Analysis
* Customer Insights
* Geographic Sales Analysis
* Interactive Filters and Drill-through
* Time Intelligence Metrics
